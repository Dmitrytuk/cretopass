# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Fixed

- The title-bar spinner now animates on Windows. Its Braille frames are not in
  the WGL4 fonts the Windows console ships, so Windows substituted one static
  placeholder glyph for every frame; the spinner now falls back to a WGL4-safe
  half-block set on Windows and keeps Braille on non-Windows terminals (an unset
  locale counts as UTF-8) ([ADR 0011](docs/adr/0011-animated-status-spinner.md)).

## [1.1.0] - 2026-11-06

### Added

- **System clipboard gateway** — copying a field from the Detail overlay now
  goes through `arboard` on every platform (Win32 `CF_UNICODETEXT` on Windows,
  so non-ASCII secrets survive), falling back to
  `pbcopy`/`wl-copy`/`xclip`/`xsel` where needed, and reports the outcome as a
  success or failure modal instead of assuming success. On Windows the old
  helper-only path never ran yet reported "Copied!" with an empty clipboard.
  See [ADR 0025](docs/adr/0025-clipboard-gateway.md).
- **Paste with `Ctrl+V`** — text can be pasted from the system clipboard into
  any text field. Bracketed paste is enabled, so a multi-line paste arrives
  atomically and is joined into a single line, and `Ctrl+V` never types the
  letter `v`. The clipboard is read off the UI thread, so a slow clipboard
  cannot freeze the app.
- **Deterministic mouse input** — the wheel scrolls every list identically, and
  a left click is hit-tested into the same action its key produces (a click
  selects a row, a repeat click activates it); a right-click on a detail row
  copies its value, and a click outside a modal panel dismisses it. Native
  terminal text selection is off while the app runs; hold `Shift` to select
  text. See [ADR 0026](docs/adr/0026-deterministic-mouse-input.md).

### Changed

- Browsing no longer reads any file contents: the file browser consults only
  the entry file type, so a cloud-sync placeholder is never hydrated. On
  Windows this removes a hang when the provider raised a consent dialog behind
  the full-screen TUI. `FileEntry::is_age_file` becomes the name-only
  `looks_like_vault` hint, and the export overwrite guard is name-only too
  ([ADR 0022](docs/adr/0022-user-chosen-export-destination.md),
  [ADR 0024](docs/adr/0024-browsing-never-reads-file-contents.md)).
- Directory listings and mounted-disk enumeration now run on detached
  background threads with a bounded wait and a generation counter, so a slow
  or hung filesystem (a disconnected share, a cloud folder) can no longer
  freeze the TUI ([ADR 0024](docs/adr/0024-browsing-never-reads-file-contents.md)).
- The file browser's `f` filter is gone — the hidden-entry toggle and search
  already cover its use case, and the mode badge now always reports the real
  mode.

### Removed

- `cretopass update` (in-app self-update) is gone: the binary no longer contains
  any network code, so a local password manager never downloads or executes
  remote code. Update by re-running the installer or through your package
  manager ([ADR 0027](docs/adr/0027-no-in-app-network-access.md)).

### Fixed

- The file browser now reports a delete the filesystem has not applied yet (a
  Windows sync client may still hold the file open) with a dismissable
  non-fatal notice, instead of silently re-listing the surviving row.
- Clipboard helper programs are resolved only from trusted directories, and
  their captured output is wiped after use.
- A click outside a popup now dismisses only the popups the File Browser has
  actually drawn, so it no longer closes a surface that is not on screen.
- The Tree's collapsed-node arrow is a WGL4-safe glyph that renders in the
  Windows console font, and the obsolete `Root`/`Mouse` lines were dropped from
  the in-app Help list.
- `LICENSE-THIRD-PARTY` is complete again: it lists every normal and build
  dependency for all supported targets and is regenerated by
  `scripts/gen-third-party-licenses.py` (with full BSD-3-Clause and
  Apache-2.0 texts), and the licence files now ship inside every release
  archive.

### Security

- Typed and pasted field input is capped at 8 KiB, and control characters are
  stripped before they reach a field, so a paste cannot smuggle terminal
  escapes or unbounded data into the vault.

## [1.0.0] - 2026-11-03

### Added

- **Share** a node (with or without its children) or the whole vault as a
  still-encrypted bundle the recipient opens in cretopass with their own
  password. Reached from the Tree with `Ctrl+E` then `s`, or from Home's "Share
  active file". The File Browser
  names the bundle folder, which gets a `<stem>.cretopass` file and a
  plain-text `HOW-TO-OPEN.txt`; the password is never written into the bundle.
- File browser can switch to mounted disks through a `Locations` overlay
  (`D`), toggle hidden dot-entries with `Ctrl+h` (or `Ctrl+Backspace`), and
  remember the last browsed directory and hidden setting for the rest of the
  session.
- The import file browser advertises the accepted formats (`json`/`csv`/`xml`)
  at the head of its status-bar hint.
- Home has an **About** overlay (press `?`): app name, version, tagline, the
  GitHub Issues link, the private security-reporting form, and the MIT license
  link. Any key dismisses it.
- `cretopass --help` now ends with the same app version, feedback links, and
  license. The strings are shared constants in `theming`, so the TUI overlay
  and the CLI help cannot drift apart. `cretopass --version` is unchanged.
- GitHub issue forms (bug report, feature request), `SECURITY.md`, and a README
  feedback section establish the project's feedback channel: ordinary reports
  go to GitHub Issues, security vulnerabilities through GitHub Private
  Vulnerability Reporting.

### Changed

- All screens now draw a single unified status bar (`[MODE] hints`) instead of a
  separate status line and help line. The Tree drops its `N items`/query context
  row; Home's static ` HOME ` label becomes a mode badge that reflects the open
  modal; the file browser no longer draws a status line of its own — the Home
  window renders its badge and hints (the `Hidden: on/off` and `Filter:`
  indicators are gone, with the `[PWD]` filter badge replacing the mode badge in
  every file-browser mode).
  Badge colours now encode the risk of the active action and mean the same thing
  in every screen.
- Modal windows no longer repeat their key hints inline: the Tree overlays, the
  Home modals, the File Browser name/rename/delete/error and `Locations` popups
  and the save-error / discard-confirm overlays all defer to the status bar.
  Because the File Browser draws no status bar, it routes its badge and hint
  through the owning Home window's status line.
- The file browser list and `Locations` overlay keep a 3-row margin around the
  cursor (`scrolloff`-style). The cursor moves within that margin before the
  viewport scrolls in either direction, instead of staying pinned to the bottom
  edge.
- Node descriptions are now ordinary extra fields (a `Custom` field labelled
  "Description") instead of a dedicated `description` slot. Descriptions can be
  added, reordered, duplicated and deleted like any other field, and a node has
  no description until one is added via `+ Add Field`. Existing vaults and
  exported XML/CSV/JSON files are migrated automatically on load: a non-empty
  legacy description becomes a leading Description field. The serialized format
  no longer contains a `description` key.
- The Home status-bar hint now lists `?:about`, so the new About overlay is
  discoverable from the menu.
- The `generator` sub-modules are now an implementation detail: password and
  login generation are reached through the module's re-exports
  (`cretopass::generator::{…}`) instead of the redundant `generator::password` /
  `generator::login` paths. No public item was removed.

### Fixed

- A cut node is now removed from the cut buffer after a successful paste, so it
  can no longer be pasted repeatedly. Previously each paste inserted a clone
  that kept the original node id, letting multiple nodes share one id.
- `p` in the tree no longer enters the paste prefix mode when the cut buffer is
  empty; the key is a no-op until something is cut.

## [0.1.0] - 2026-10-13

### Added

- Terminal UI for managing secrets with vim-style navigation (`h/j/k/l`, `gg`, `G`).
- Custom tree data structure for organising entries into folders and leaves.
- Search and filter across the tree.
- Edit and add forms for entries.
- In-memory editing with atomic autosave to an age-encrypted file.
- Home screen with multiple vaults and persisted configuration.
- File browser overlay for selecting vault and import/export paths.
- Theming layer with configurable styles, icons and strings.
- CLI subcommands: `cretopass update` (self-update via the installer) and
  `cretopass remove` (uninstall all artifacts).
- `install.sh` (Linux/macOS) and `install.ps1` (Windows) release installers
  with checksum verification, PATH integration, shell completions and GUI
  integration.
- Static musl builds for Linux, ad-hoc signed builds for macOS, and static-CRT
  builds for Windows (x86_64 and ARM64).
